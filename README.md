# SWYNEX Python CLI Application

## Project Overview

A simple command-line Task Manager application developed using Python. It helps users manage daily tasks through a menu-driven interface.

## Features

* Add new tasks
* View all tasks
* Mark tasks as completed
* Delete tasks
* Handle invalid inputs
* Store tasks using JSON

## Technologies Used

* Python
* JSON
* Git
* GitHub

## Project Files

* `main.py` – Runs the main menu and handles user interaction.
* `task_manager.py` – Contains functions to add, view, complete, and delete tasks.
* `tasks.json` – Stores task data locally.
* `.gitignore` – Excludes unnecessary files from Git tracking.

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run the following command:

   ```bash
   python main.py
   ```
